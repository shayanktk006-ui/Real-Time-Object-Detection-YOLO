# Real-Time Object Detection with YOLO

## Project Overview

A real-time object detection system built with Python, OpenCV, and YOLO.

The system detects objects from a webcam stream, displays bounding boxes, class names, confidence scores, and FPS in real time.

## Features

- Real-time object detection
- Webcam-based detection
- Bounding boxes and class labels
- Confidence scores
- Confidence threshold control
- Real-time FPS display
- Screenshot capture
- Error handling
- Clean reusable functions
- One-click project launcher

## Technologies Used

- Python
- OpenCV
- Ultralytics YOLO
- YOLO11 Nano
- Computer Vision
